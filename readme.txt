# Expense Calculator

## Overview
Expense Calculator is a Python-based application that helps users track their daily expenses and calculate total spending.

## Features
- Add expenses with category and amount
- View all expenses
- Calculate total expenditure
- Monthly expense tracking
- User-friendly menu-driven program

## Technologies Used
- Python

## Concepts Used
- Loops
- Conditional Statements
- Lists
- User Input Handling
- Functions

## Future Improvements
- File storage
- Database integration
- GUI version using Tkinter
